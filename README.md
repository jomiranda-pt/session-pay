# Session Pay

Aplicativo simples para profissionais autônomos controlarem clientes, sessões, pacotes e pagamentos.

## Objetivo

Facilitar o controle financeiro de profissionais que trabalham por sessões, como personal trainers e fisioterapeutas.

## MVP - Primeira versão

### Clientes
- Nome
- Telefone
- Valor da sessão
- Frequência semanal
- Dias e horários habituais
- Observações
- Cliente ativo ou inativo
- Forma de cobrança

### Formas de cobrança
- Por sessão
- Semanal
- Quinzenal
- Mensal
- Pacote pré-pago

### Sessões
Cada sessão deve registrar:
- Cliente
- Data
- Status: realizada, falta ou cancelada
- Valor
- Se a sessão deve ser cobrada ou não
- Situação do pagamento

### Pacotes
O profissional poderá cadastrar:
- Quantidade de sessões do pacote
- Valor total do pacote
- Quantas sessões já foram utilizadas
- Quantas sessões ainda restam

Uma falta poderá ou não descontar uma sessão do pacote, conforme escolha do profissional.

### Pagamentos
Cada cliente poderá ter sua própria forma de controle.

O profissional poderá marcar pagamentos:
- Por sessão
- Por semana
- Por quinzena
- Por mês
- Por pacote

### Resumo
O painel deverá mostrar:
- Total de sessões
- Valor total gerado
- Valor já pago
- Valor em aberto
- Resumo individual de cada cliente
- Sessões restantes dos clientes que utilizam pacotes

## Princípio do projeto

Primeiro fazer funcionar. Depois sofisticar.
